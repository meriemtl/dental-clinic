Only needed if you run the project WITHOUT Maven (run-without-maven.bat).

Put these two jar files in this folder:
  - mysql-connector-j-8.x.x.jar   https://dev.mysql.com/downloads/connector/j/   (choose "Platform Independent")
  - jbcrypt-0.4.jar               https://repo1.maven.org/maven2/org/mindrot/jbcrypt/0.4/jbcrypt-0.4.jar

With Maven (recommended) this folder is not used: the dependencies are downloaded automatically.
